# Roadmap

## V0.1 — current foundation

Core UI, profile, daily questions, date ideas, lightweight games/challenges, pet care, Room history, DataStore persistence, demo partner switching, relationship statistics and first Android widget.

## V0.2

Two-sided answer reveal, full quiz engine, more games, custom mood/status, richer scrapbook filters, achievements, pet inventory and room decoration.

## V0.3

Multiple Android widget sizes, photo widget, doodle widget, mood widget, pet widget, countdown widget and widget configuration UI.

## V0.4

Secure partner pairing, authenticated remote sync, push notifications, conflict handling, data export and deletion.

## V0.5

Guided journeys, shared calendar, collections, custom themes, richer evidence-informed activity insights and optional astrology entertainment clearly separated from those insights.
